# JeuxDeCartes

Petit projet de jeu de cartes réalisé avec Qt Creator et C++.

## Fonctionnalités

- Interface graphique avec Qt
- Distribution des cartes
- Mélange aléatoire des cartes
- Images des cartes et fond de table
- Fenêtre de jeu interactive

## Technologies utilisées

- C++
- Qt Creator
- Qt Widgets
